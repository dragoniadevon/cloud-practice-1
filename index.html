Про застосунок

Цей вебзастосунок створено у хмарному середовищі GitHub Codespaces та розгорнуто за допомогою GitHub Pages.

Хмарні технології

  • GitHub — зберігання програмного коду
  • GitHub Codespaces — хмарне середовище розробки
  • GitHub Pages — розгортання вебзастосунку

Інформація про студента

Виконала: Вареник Анастасія Дмитрівна

Хмарний сервіс: Vercel

Призначення: платформа для розгортання та хостингу сучасних вебзастосунків із автоматичним деплоєм після кожного push до Git-репозиторію.

Моделі хмарних послуг: PaaS (платформа для розгортання застосунків); FaaS/serverless (Serverless та Edge Functions).

Приклади сервісів і функцій: глобальна Edge Network (CDN), Serverless Functions, Preview Deployments для кожної гілки, Vercel Blob та інші сховища даних.

Офіційний сайт: vercel.com
